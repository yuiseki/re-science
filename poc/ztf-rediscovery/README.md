# ztf-rediscovery

ZTF のアーカイブで見落とされていた核過渡現象を、アラート測光と固定スコアだけで、背景の天体からどれだけ分けられるかを測る。

新しい現象は探していない。測ったのは、既に見つかっているものを拾い直すときの絞り込みの効率である。

## 問い

Quintin ら「Lost and Found」([arXiv:2511.19016](https://arxiv.org/abs/2511.19016)、CC BY 4.0) は、Fink の TDE 分類器と目視で、ZTF のアーカイブから23天体を拾った。核過渡現象が19件 (TDE 候補9、活動銀河のフレア8、判別不能2)、超新星候補が4件である。

この23天体を正解表にし、同じ時期に Fink が流したほかの天体 (背景) と混ぜて、同じスコアをかける。

## データ

- 正解表: `data/ground_truth.tsv`。論文の表1から書き写した
- 背景: `data/background.tsv`。2019-11 から 2025-06 の間の乱数で選んだ30週について、Fink の5つの分類から最大4天体ずつ引いた 484 天体。種は固定してある
- 光度曲線: Fink の API (`api.ztf.fink-portal.org`) から取るアラート測光。`cache/` に置き、リポジトリには入れない

背景の5分類は、正解表のアラートに Fink が付けていた分類 (Unknown、Galaxy、QSO、Seyfert_1) と、超新星候補である。

## スコア

`score.py` の6つの基準のうち、いくつ満たすかを数える。van Velzen ら (2021) の ZTF の TDE 選別の基準から書き起こした。

| 基準 | 条件 |
|---|---|
| galaxy_host | PS1 の星らしさ sgscore が 0.5 未満 |
| nuclear | PS1 の最寄り天体までの距離が 0.6 秒角未満 |
| blue_at_peak | ピーク付近の g − r が 0 未満 |
| no_reddening | ピーク後の g − r の変化が 1 日あたり 0.015 等未満 |
| long_lived | ピークを含むフレアが 60 日以上続く |
| well_sampled | 正の検出が 10 点以上 |

値が無い基準は、満たさない側に数える。スコアは正解表の光度曲線を取得する前にコミットした (7819884)。

### 読み取れること

- 主張 C1 は規則のうえで支持された。Unknown と超新星候補の層では、スコア 5 以上で背景の 1〜4% しか残らず、核過渡現象は 74% が残る
- 既知の活動銀河の層では分かれ方が弱い。QSO の 24%、Seyfert_1 の 39% がスコア 5 以上になる。活動銀河の中心は、もともと核にあり、青く、長く光るからである
- 正解表の19件のうち8件は活動銀河で起きたフレアである。論文は「既知の活動銀河を探索から機械的に外すべきでない」と書いている。このスコアが絞れないのは、まさにその領域である
- 超新星候補4件は 3〜4 点で、5 以上は無かった。負の対照として期待した向きだが、これは計画を書く前に見ていたので、探索として扱う
- 背景の 484 件のうち 160 件は、正の検出が1つも無くスコア 0 になった。参照画像より暗くなった側だけが記録された天体である

### 落ちた正解

スコア 5 未満だった核過渡現象は5件ある。

| 天体 | スコア | 満たさなかった基準 |
|---|---|---|
| ZTF21aazenvp | 4 | no_reddening (色の対が足りない)、long_lived (53 日) |
| ZTF23abjvojy | 4 | galaxy_host (sgscore 0.64)、no_reddening (色の対が足りない) |
| ZTF23abowyjf | 4 | blue_at_peak と no_reddening (色の対が無い) |
| ZTF21abvydim | 3 | galaxy_host (sgscore 0.96)、blue_at_peak、no_reddening |
| ZTF20aatpzog | 2 | 正の検出が5点しか無く、色も継続時間も出ない |

5件のうち4件は、色を測るための g と r の同時観測がアラートに足りなかった。論文は強制測光を使っており、アラート測光より点が多い。落ちた主な理由はデータの差である。

## この結果が言えないこと

- スコアの発見力。正解表は TDE の分類器と目視で選ばれた。TDE らしさのスコアが高く出るのは、選ばれ方から当然である
- 全体の Inspection Load。背景は層ごとに同数を引いた。実際のアラートは Unknown が大半で、層の重みを付け直していない
- 背景の代表性。「ある週にアラートが出た天体」から引いたので、アラートの多い天体ほど選ばれやすい。Galaxy の層は 2022 年半ば以降が 0 件で、それ以前しか代表していない
- しきい値 5 の妥当性。背景を見る前に決めたが、正解表の値は見た後だった

## していないこと

- 基準の順位 (アラートの数だけで並べるなど) との比較
- 設定を変えたときの頑健性 (フレアを分ける間隔、週の取り直し、強制測光)
- 合成した天体を入れて回収率を測る試験
- TNS との照合と、新しい候補の探索

## 再実行

```sh
uv run pytest
uv run python fetch_objects.py data/ground_truth.tsv cache/objects
uv run python fetch_objects.py data/background.tsv cache/objects
uv run python evaluate.py data/ground_truth.tsv data/background.tsv cache/objects
```

`sample_background.py` は `data/background.tsv` を作り直す。取得は1天体に数秒かかり、全体で約40分である。
