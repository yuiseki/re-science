# 計画: ZTF の見落とし現象は、固定スコアで背景から分けられるか

流す前に書く。流した後に書き直さない。直すなら末尾の「計画の変更」に足す。

書式は GeoAI-master-skills の experiment-design の短い版に従う。主張が1つ、決め手の比較が1つである。

## 問いと使い道

- 問い: Lost and Found の核過渡現象を、アラート測光と固定スコアだけで、背景の天体からどれだけ分けられるか
- 使い道: このスコアで目視の候補を絞る意味があるかを決める。意味が無ければ、新しい候補の探索へは進まない
- 問いの種類: 関連、構造

## 主張

C1: スコアが 5 以上になる割合は、正解表の核過渡現象 (TDE、ANT、判別不能の19件) のほうが、背景の Unknown 層より高い。

Unknown 層を主にする理由は、実際のアラートの大半がこの分類だからである。2022-03-03 の夜の統計では Unknown が約 10 万件、超新星候補が約 1,000 件だった。

## 区画 B1

- mode: 確認。ただし下の「流す前に決めたこと」のとおり、正解表の側の値は見ている
- data / analysis unit: 1行は1天体。正解表23件、背景 484 件 (30 週 × 5 分類 × 最大 4 天体、種は固定)
- observable quantity: スコア 5 以上の割合
- comparator: 背景の各層。主は Unknown、補助は SN candidate、QSO、Seyfert_1、Galaxy
- primary metric: 割合の差 (正解表 − Unknown 層)
- uncertainty: 差の 95% 区間 (Newcombe の方法)。乱数は使わないので種は無い
- planned settings: score.py と features.py をコミット 7819884 の内容のまま使う
- decision rule:
  - 支持: 差の 95% 区間の下限が 0 より大きい
  - 退ける: 差の点推定が 0 以下
  - 判断できない: それ以外
- 数の閾値を置かない理由: 「何倍絞れれば使える」の根拠になる業務の要件が無い。向きと不確かさだけで判定し、絞れる倍率は記述として報告する
- failure interpretation: 退けられたら、van Velzen らの測光の基準をアラート測光に当てただけでは、この23件は背景と区別できないと分かる。その場合に、しきい値、FLARE_GAP_DAYS、背景の層の選び方を変えたり、アラートの少ない正解を除いたりして、同じ主張を支持しない

## 別の説明

| 別の説明 | この比較で起こるか | 扱い |
|---|---|---|
| 循環 | 起こる。正解表は TDE の分類器と目視で選ばれた。TDE らしさのスコアが高く出るのは選ばれ方から当然である | 主張を「絞り込みの負荷」に限り、スコアの発見力については何も言わない |
| 観測の努力 | 起こる。n_det と duration は、その領域の観測頻度と、天体が何年追われたかで決まる | well_sampled と long_lived の通過率を層ごとに並べて報告する。補正はしない |
| 標本の偏り | 起こる。背景は「ある週にアラートが出た天体」から引いたので、アラートの多い天体ほど選ばれやすい | 背景が長寿命・多観測の側に寄るので、主張には不利に働く。その向きを報告に書く |
| リーク | 起こりうる。Fink の d:tns には論文の後の分類が入っている | d:tns と d:cdsxmatch はスコアに使わない |
| 層の欠け | 起こる。Galaxy の層は 2022 年半ば以降が 0 件である | Galaxy は補助の層とし、代表する期間を書く |
| 偶然 | 起こる。正解表は19件しかない | 差の区間で見る |

## 反証と頑健性

- 負の対照: 同じ論文の超新星候補4件は、核過渡現象より通過率が低いはずである。これは既に見た (4件とも 5 未満) ので、探索として報告する
- 頑健性 (FLARE_GAP_DAYS、週の取り直し、強制測光との比較) は今回は流さない。流していないことを報告に書く
